# Car Price Prediction

A Machine Learning project that predicts used car selling prices using Linear Regression.

## Project Overview

The goal of this project is to build a regression model that can predict the selling price of a used car based on several features such as year, present price, kilometers driven, fuel type, seller type, transmission, and ownership history.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Model

Linear Regression

## Model Performance

- R² Score: 0.849
- MAE: 1.216
- MSE: 3.479
- RMSE: 1.865

## Project Workflow

1. Load the dataset
2. Explore and understand the data
3. Check for missing values
4. Preprocess categorical features
5. Split the data into training and testing sets
6. Train the Linear Regression model
7. Make predictions
8. Evaluate the model
9. Visualize actual vs predicted prices

## Conclusion

The Linear Regression model achieved an R² score of approximately 0.85 on the test set, showing that the model captures a substantial portion of the variation in used car selling prices.
